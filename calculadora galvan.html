Datos generales

Monto total contra el que se calcula MÁRQUEZ por diferencia.

Porcentajes

Se calcula como MATÍAS + THIARA.

Regla protegida

PAREDES se calcula al 18%.

BANEGAS se divide en dos: MATÍAS 11% y THIARA 11%.

MÁRQUEZ no se calcula por 60% directo: se calcula como RAET - PAREDES - BANEGAS.

Sueldo base PAREDES

PAREDES usa su propia base de sueldo.

Base PAREDES = bruto - descuento % + no remunerativo - seguro - AFIP que resta + AFIP que suma.

Sueldo base BANEGAS

MATÍAS y THIARA usan la misma base BANEGAS.

Base BANEGAS = bruto - descuento % + no remunerativo - seguro - AFIP que resta + AFIP que suma.

SAC PAREDES

Opcional. Si no corresponde, dejar en cero.

SAC BANEGAS

Opcional. Se aplica a MATÍAS y THIARA según sus porcentajes.
